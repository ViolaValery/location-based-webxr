    Tour editor

    Open a tour

    Edit on the computer what you created on the phone: fix a text, move a pin to where it belongs, remove what does not.

    or

    In Chrome and Edge your edits are saved into the file as you go. Firefox and Safari cannot write to a file you opened: there you get an explicit Save that downloads a new file, and your edits are kept on this computer in between.

    Prototype: any file you pick opens the sample tour under its name. Nothing is read or written.

    Listed tour

    Publish a new version

    This tour is listed, so visitors open its signed versions. Publishing adds one new signed version for this whole editing session. Your saves along the way are not versions of their own. If you close the editor without publishing, the version is made when you close.
